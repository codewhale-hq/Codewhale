## Optional compiled extension host

Node remains the default extension-host runtime. An explicitly installed
`codewhale-extension-host` compiled Bun image carries its exact-build runtime
notices in `codewhale-extension-host.LICENSES.txt` and its corresponding source
and relinking inputs in `codewhale-extension-host.relink-source.tar.gz`. These
are required companions, separate from this repository's Rust/JavaScript
dependency notices. No image is eligible for release delivery until both the
matching-native containment evidence and the exact runtime notice/source
closure are complete.

Bun's matching source license identifies statically linked LGPL JavaScriptCore,
WebCore, and TinyCC, as well as other linked and embedded dependencies. The
release preparation contract is documented in
`scripts/release/compiled-host-licenses/README.md`. This file does not replace
the full notices carried with an eligible compiled image.
