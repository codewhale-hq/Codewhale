# 鲸鱼视图

> 英文原文：[PET_MODE.md](../PET_MODE.md)。
> 最后与英文同步日期（last synced with English revision）：2026-11-25。

`/whale` 把你正在使用的终端变成一个一眼可读的状态视图。一头由点组成的鲸鱼占据主视图，显示会话正在做什么：空闲、工作中、在等你、已完成或失败。消息框始终留在底部，你可以继续输入；回复和智能体只需按一个键即可查看。

每个终端根据各自的会话绘制各自的鲸鱼。除此之外没有别的东西在运行：没有后台进程，没有端口，也没有共享状态。同时打开多个终端时，你可以逐个扫一眼：哪个需要你、哪个还在工作、哪个已经完成。

## 命令

| 命令 | 效果 |
| --- | --- |
| `/whale` | 为当前终端开启或关闭鲸鱼视图。`/whale on` 和 `/whale off` 直接设定，不做切换。 |
| `/whale full` | 与 `/whale` 相同。在终端里鲸鱼视图本身就是完整视图；保留这个词是为了让命令与桌面应用一致。 |
| `/whale still` | 让鲸鱼保持静止，或让它重新动起来。 |
| `/whale name <文字>` | 给鲸鱼起名。名字会取代视图第一行的 `Codewhale`，最多 32 个字符。 |
| `/whale color <名称|#rrggbb>` | 用桌面应用的颜色（`scout`、`patch`、`harbor`、`echo`、`keel`、`lantern`、`violet`、`amber`）或十六进制值给鲸鱼上色，每个点保留自己的明暗。`/whale color default` 恢复鲸鱼原本的颜色。 |

`/pet` 仍然会运行 `/whale`，后面的词也相同，因此旧习惯和旧脚本继续可用。它不再出现在帮助和补全里。

视图的开关会保存为 `pet_mode` 设置（也可在设置编辑器中修改），新会话会沿用你上次的选择。名字和颜色保存在同一个 `settings.toml` 的 `whale_name` 和 `whale_color` 中，是所有终端和桌面应用共用的同一身份：在桌面应用的“关于”页、`/whale` 或 `/config` 中修改后，正在显示鲸鱼的终端会在两秒内更新。静止状态只保留到当前终端关闭为止。

鲸鱼视图不会发起回合、不会调用模型，也不会改动你的草稿、模式或审批；它只呈现你已在运行的会话。

## 鲸鱼告诉你什么

视图第一行和鲸鱼下方的标记始终同时给出标记与文字，因此不依赖颜色或动效：

| 状态 | 标记与文字 | 含义 |
| --- | --- | --- |
| 就绪 | `○ idle` | 没有任务在运行。 |
| 工作中 | `● working` | 回合正在运行，包括工具调用与验证。 |
| 需要你 | 等待或审批阶段 | 会话在等你审批或回答。等待期间动效会减弱。 |
| 已完成 | `✓ Done` | 上一个回合已完成。 |
| 失败 | `✕ failed` | 上一个回合以失败结束。 |

回合运行时，鲸鱼的点会离开鲸鱼，变成正在进行的工作本身并动起来，然后回到鲸鱼：命令和工具是扳手，编辑是铅笔，读取是书本，搜索是放大镜，测试是烧瓶，浏览是地球仪，操作电脑是指针，记忆是叠放的层，思考是灯泡，回复是对话气泡，并行智能体是一群小鲸鱼，需要你时是摇响的铃，完成时是对勾。保持静止或减弱动效时，显示该形状的一个静止姿态。

下方状态栏保留原有的实时读数，例如智能体数量（`2 agents`）和任务面板。重试等临时提示显示在第二行。

## 按需查看回复与智能体

主视图保持安静。鲸鱼视图开启时按 `F5`，或点击提示行，在其上打开检查视图：

- 上方是鲸鱼和 **Agents** 列表，列出每个智能体的状态与用量；
- 下方是 **Reply** 面板，流式显示当前回答，并显示同一会话的终端错误。

| 按键 | 效果 |
| --- | --- |
| `F5` | 打开回复与智能体。 |
| `Esc` | 回到消息框。你的草稿、对话记录和正在运行的回合都不受影响。 |
| `Tab` | 在 Reply 和 Agents 面板之间切换。 |
| `Up` / `Down`、`PgUp` / `PgDn`、`Home` / `End` | 滚动当前面板。 |
| `Enter`（Agents 面板） | 打开所选智能体的对话记录。 |
| `c` | 复制最近一条已完成的回复，与 `/copy` 走同一条路径。 |

在 Mac 键盘上，顶排按键默认发送媒体键，需要按住 Fn，因此 TUI 各处（包括帮助）的 F 键提示写作 `fn+F5`；请同时按 Fn。

## 多个终端，各有一头鲸鱼

在两个终端里启动 Codewhale 并各自运行 `/whale`：每头鲸鱼跟随自己的会话，所以一个可以显示 `✓ Done`，另一个显示 `● working`。会话之间互不混合，终端之间也不通信。桌面应用用同一份代码绘制同一头鲸鱼，显示的是它自己的会话。

## 点阵无法绘制时

- **`CODEWHALE_ASCII_SAFE=1`。** 标记、边框和指针使用 ASCII（`o idle`、`|`、`>`）。鲸鱼由状态标记和文字代替，标题下一行会说明这一点。
- **小终端。** 点阵鲸鱼需要至少 16x8 个单元格的图案区域；不足时仍保留标记、文字、提示行和消息框。
- **点阵鲸鱼无法启动。** 视图改为绘制半块字符鲸鱼，标题下一行会说明这一点。状态标记和文字照常工作，因为它们来自你的会话。
- **`NO_COLOR`。** 颜色交给你的终端；标记和文字仍然表达状态。
- **减弱动效。** 跟随 shell 的动效设置，显示静止姿态。

## 隐私

鲸鱼在终端进程内绘制。它从会话读取的只是一份很短的允许列表：事件种类、标识和结果（例如“开始读取”“回合完成”）。提示词、推理、工具名称、参数、结果和路径都不会被读取；不写磁盘，不向任何地方发送，也不会改变会话的模型上下文。

## 0.10.5 移除的内容

早期版本会在回环端口上运行一个共享的伴生进程（`codewhale pet serve`）。它已被移除，只有它才提供的功能也一并移除：

- 声音（`/pet sound`、`F6`）；
- 回放录制与 `/pet export`；
- 浏览器外观工作室（`/pet appearance`、`F8`）与 `/pet style`；
- 来源选择（`/pet source`）与 `/pet status`；
- 其他视图（`cove`、`braille`、`pixels`、`particles`、`whale-girl`）、视图切换、`/pet avatar`、`/pet action`、`/pet view`，以及终端里的头像包；
- `/pet inspect`；请使用 `F5`。

`CODEWHALE_PET_HOME`、`CODEWHALE_PET_PORT` 和 `CODEWHALE_PET_GRAPHICS` 不再被读取。旧版本留在 `~/.codewhale/pet-shared` 里的文件不会被读取，也不会被删除；你可以自行删除该文件夹。

## 已知限制

- **还没有“回复已就绪”的提示。** 回合结束时，鲸鱼显示 `✓ Done`，页脚提示仍是同一行静态文字。没有单独的通知、徽标或声音告诉你有回复在等。请看状态文字，或按 `F5` 阅读回复。
- **智能体行可能滞后。** 智能体运行期间，检查视图里的 Agents 列表在回合结束时刷新，而不是每次变化都刷新。状态栏的智能体数量和任务面板是实时的；回合结束前，请把检查视图里的行当作快照。
- **鲸鱼起初处于未观测状态。** 同一个 Codewhale 进程里第一次 `/whale` 之前的事件不会显示；鲸鱼会休息到下一个事件到来。
- **名字、颜色和静止状态不会保存**，也不会与其他终端或桌面应用共享。
- **颜色会取代活动色调。** 形状、标记和文字仍然说明会话在做什么。
- **鲸鱼视图显示时，任务面板被隐藏。** 用 `/whale` 关闭视图后再使用它。
